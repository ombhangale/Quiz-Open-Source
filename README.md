🌍 Live Demo

🧩 Overview

This project is a browser-based quiz system where users can:

- Enter their name
- Attempt multiple-choice questions
- Get instant feedback with final score

---

🧱 Tech Stack

Technology| Usage
HTML| Structure
CSS| Styling
JavaScript| Logic & Functionality

---

📁 Project Structure

Quiz-Open-Source/
│
├── index.html      → Main entry point
├── style.css       → UI styling
├── script.js       → Quiz logic
├── README.md       → Documentation
└── assets/         → Images / resources

---

🚦 How It Works

1. User enters their name
2. Quiz starts with multiple questions
3. User selects answers
4. Score is calculated instantly
5. Final result is displayed
